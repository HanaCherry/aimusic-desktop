## Ένα στούντιο στα μέτρα σου

- **Ενσωματωμένο player** — Σταθερό εξώφυλλο, διαφανής μπάρα, έγχρωμη πρόοδος και χειριστήρια αναπαραγωγής στο κάτω μέρος.

- **Χρώματα και ατμόσφαιρα** — Galaxy, Μουσική, Νύχτα, Φωτεινό και Επίσημο. Τα χρώματα του εξωφύλλου συνοδεύουν την ακρόαση.

- **Ισοσταθμιστής και εφέ** — Δέκα ζώνες, προενισχυτής, προφίλ, A/B, στερεοφωνικό πλάτος, πανοραμική θέση, auto-pan, αντήχηση, ηχώ και φάσμα.

- **Τοπικό προφίλ** — Πρόσθεσε φωτογραφία και ψευδώνυμο. Οι προτιμήσεις και τα προφίλ ήχου μένουν στον υπολογιστή σου.

- **Cache εκκίνησης** — Η cache δίσκου επαναχρησιμοποιεί διαθέσιμους πόρους. Η εκκαθάριση διατηρεί συνεδρία και ρυθμίσεις.

- **Ορατές πιστώσεις** — Δες το υπόλοιπο AI Music και χρησιμοποίησε τα πραγματικά εργαλεία της υπηρεσίας.

## Έτοιμος να ανοίξεις το στούντιό σου;

1. Κατέβασε το πρόγραμμα εγκατάστασης Windows από την έκδοση. → [v0.4.0](https://github.com/HanaCherry/aimusic-desktop/releases/tag/v0.4.0)
2. Εκτέλεσε το αρχείο .exe και ακολούθησε την εγκατάσταση.
3. Άνοιξε το AI Music Desktop και συνδέσου στην υπηρεσία αν χρειάζεται.

> Το πρόγραμμα εγκατάστασης δεν είναι υπογεγραμμένο· τα Windows μπορεί να εμφανίσουν προειδοποίηση.

## Ανεξάρτητο έργο

Ανεπίσημη εφαρμογή χωρίς σχέση με το AI Music. Απαιτεί Internet. Τα εφέ και η ανάλυση εξαρτώνται από την πρόσβαση στη ροή ήχου· οι συνθετικές δοκιμές δεν εγγυώνται κάθε απομακρυσμένο κομμάτι.

Η παρουσίαση διατίθεται σε 32 γλώσσες. Η τοπική διεπαφή είναι προς το παρόν στα γαλλικά· η γλώσσα της υπηρεσίας επιλέγεται στο μενού της.

→ [NOTICE.md](NOTICE.md) · [aimusic.so](https://aimusic.so/fr/app)

## Ανάπτυξη

Node.js 22.12+ · pnpm · Windows x64

```sh
git clone https://github.com/HanaCherry/aimusic-desktop.git
cd aimusic-desktop
pnpm install --frozen-lockfile
node node_modules/electron/install.js
pnpm start
```

```sh
pnpm test
pnpm exec electron . --smoke-test
pnpm exec electron . --preview
pnpm dist
```

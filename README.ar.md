## استوديو يناسبك

- **مشغّل مدمج** — غلاف ثابت وشريط شفاف وتقدّم ملوّن وعناصر تشغيل مجمّعة في الأسفل.

- **ألوان وأجواء** — سمات Galaxy والموسيقى والليل والفاتح والرسمية. ترافق ألوان الغلاف الاستماع.

- **معادل ومؤثرات** — عشرة نطاقات وتضخيم أولي وإعدادات مسبقة وA/B وعرض ستيريو وتحريك صوتي وتحريك تلقائي وصدى وارتداد وطيف.

- **ملفك محلي** — أضف صورة واسمًا مستعارًا. تبقى التفضيلات وإعدادات الصوت على حاسوبك.

- **ذاكرة بدء التشغيل** — تعيد ذاكرة القرص استخدام الموارد المتاحة. يحافظ مسحها على الجلسة والإعدادات.

- **رصيد ظاهر** — اطّلع على رصيد AI Music واستخدم أدوات الإنشاء الأصلية للخدمة.

## هل أنت مستعد لفتح استوديوك؟

1. نزّل مثبت Windows من صفحة الإصدار. → [v0.4.0](https://github.com/HanaCherry/aimusic-desktop/releases/tag/v0.4.0)
2. شغّل ملف .exe واتبع خطوات التثبيت.
3. افتح AI Music Desktop وسجّل الدخول إلى الخدمة عند الحاجة.

> المثبت غير موقّع؛ قد يعرض Windows تحذيرًا.

## مشروع مستقل

تطبيق غير رسمي ولا يرتبط بـ AI Music. يتطلب الإنترنت. تعتمد المؤثرات والتحليل على الوصول إلى تدفق الصوت؛ لا تضمن الاختبارات الاصطناعية عمل كل المقاطع البعيدة.

هذا العرض متاح بـ32 لغة. واجهة التطبيق المحلية حاليًا بالفرنسية؛ يمكن اختيار لغة الخدمة من قائمتها.

→ [NOTICE.md](NOTICE.md) · [aimusic.so](https://aimusic.so/fr/app)

## التطوير

Node.js 22.12+ · pnpm · Windows x64

```sh
git clone https://github.com/HanaCherry/aimusic-desktop.git
cd aimusic-desktop
pnpm install --frozen-lockfile
node node_modules/electron/install.js
pnpm start
```

```sh
pnpm test
pnpm exec electron . --smoke-test
pnpm exec electron . --preview
pnpm dist
```

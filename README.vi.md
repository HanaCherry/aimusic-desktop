## Studio theo phong cách của bạn

- **Trình phát tích hợp** — Ảnh bìa cố định, thanh trong suốt, tiến trình có màu và điều khiển phát ở phía dưới.

- **Màu sắc và không khí** — Galaxy, Nhạc, Đêm, Sáng và Chính thức. Màu ảnh bìa đồng hành khi nghe.

- **Bộ cân bằng và hiệu ứng** — Mười dải, tiền khuếch đại, cấu hình, A/B, độ rộng stereo, pan, tự động pan, reverb, echo và phổ.

- **Hồ sơ cục bộ** — Thêm ảnh và biệt danh. Tùy chọn và cấu hình âm thanh lưu trên máy tính của bạn.

- **Bộ nhớ đệm khởi động** — Bộ nhớ đệm đĩa tái sử dụng tài nguyên có sẵn. Xóa đệm vẫn giữ phiên và cài đặt.

- **Hiển thị tín dụng** — Xem số dư AI Music và dùng các công cụ sáng tạo thực của dịch vụ.

## Sẵn sàng mở studio?

1. Tải trình cài đặt Windows từ trang phát hành. → [v0.4.0](https://github.com/HanaCherry/aimusic-desktop/releases/tag/v0.4.0)
2. Chạy tệp .exe và làm theo hướng dẫn.
3. Mở AI Music Desktop và đăng nhập dịch vụ nếu cần.

> Trình cài đặt chưa ký số; Windows có thể hiện cảnh báo.

## Dự án độc lập

Ứng dụng không chính thức, không liên kết với AI Music. Cần Internet. Hiệu ứng và phân tích phụ thuộc quyền truy cập luồng âm thanh; thử nghiệm tổng hợp không bảo đảm mọi bài trực tuyến.

Bản giới thiệu có 32 ngôn ngữ. Giao diện cục bộ hiện bằng tiếng Pháp; ngôn ngữ dịch vụ chọn trong menu riêng.

→ [NOTICE.md](NOTICE.md) · [aimusic.so](https://aimusic.so/fr/app)

## Phát triển

Node.js 22.12+ · pnpm · Windows x64

```sh
git clone https://github.com/HanaCherry/aimusic-desktop.git
cd aimusic-desktop
pnpm install --frozen-lockfile
node node_modules/electron/install.js
pnpm start
```

```sh
pnpm test
pnpm exec electron . --smoke-test
pnpm exec electron . --preview
pnpm dist
```

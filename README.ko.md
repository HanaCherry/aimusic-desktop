## 나에게 맞는 스튜디오

- **통합 플레이어** — 고정 앨범 이미지, 투명 바, 색상 진행 표시와 하단에 모인 재생 버튼.

- **색상과 분위기** — Galaxy, Music, Night, Light, Official 테마. 앨범 이미지의 색상을 재생 화면에 반영합니다.

- **이퀄라이저와 효과** — 10밴드, 프리앰프, 프리셋, A/B, 스테레오 폭, 팬, 자동 팬, 리버브, 에코, 스펙트럼.

- **로컬 프로필** — 사진과 닉네임을 추가하세요. 설정과 오디오 프리셋은 컴퓨터에 저장됩니다.

- **시작 캐시** — 디스크 캐시로 사용 가능한 리소스를 재사용합니다. 삭제해도 세션과 설정은 유지됩니다.

- **크레딧 표시** — AI Music 잔액을 확인하고 서비스의 실제 제작 도구를 사용하세요.

## 스튜디오를 열 준비가 되셨나요?

1. 릴리스에서 Windows 설치 파일을 다운로드하세요. → [v0.4.0](https://github.com/HanaCherry/aimusic-desktop/releases/tag/v0.4.0)
2. .exe 파일을 실행하고 설치 안내를 따르세요.
3. AI Music Desktop을 열고 필요하면 서비스에 로그인하세요.

> 서명되지 않은 설치 파일이므로 Windows 경고가 표시될 수 있습니다.

## 독립 프로젝트

AI Music과 제휴하지 않은 비공식 앱입니다. 인터넷이 필요합니다. 효과와 분석은 오디오 스트림 접근에 따라 달라지며 합성 오디오 테스트가 모든 온라인 곡의 작동을 보장하지는 않습니다.

이 소개는 32개 언어로 제공됩니다. 앱 자체 인터페이스는 현재 프랑스어이며 서비스 언어는 해당 메뉴에서 선택합니다.

→ [NOTICE.md](NOTICE.md) · [aimusic.so](https://aimusic.so/fr/app)

## 개발

Node.js 22.12+ · pnpm · Windows x64

```sh
git clone https://github.com/HanaCherry/aimusic-desktop.git
cd aimusic-desktop
pnpm install --frozen-lockfile
node node_modules/electron/install.js
pnpm start
```

```sh
pnpm test
pnpm exec electron . --smoke-test
pnpm exec electron . --preview
pnpm dist
```

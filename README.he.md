## סטודיו שמתאים לך

- **נגן משולב** — עטיפה קבועה, פס שקוף, התקדמות צבעונית ופקדי נגינה מרוכזים בתחתית.

- **צבעים ואווירה** — ערכות Galaxy, מוזיקה, לילה, בהיר ורשמית. צבעי העטיפה מלווים את ההאזנה.

- **אקולייזר ואפקטים** — עשרה תחומים, קדם-מגבר, הגדרות מוכנות, A/B, רוחב סטריאו, פאן, פאן אוטומטי, ריוורב, אקו וספקטרום.

- **פרופיל מקומי** — הוספת תמונה וכינוי. ההעדפות והגדרות השמע נשארות במחשב שלך.

- **מטמון בהפעלה** — מטמון הדיסק משתמש מחדש במשאבים זמינים. ניקוי שומר את ההפעלה וההגדרות.

- **קרדיטים גלויים** — צפייה ביתרה של AI Music ושימוש בכלי היצירה המקוריים של השירות.

## מוכנים לפתוח את הסטודיו?

1. הורידו את מתקין Windows מדף הגרסה. → [v0.4.0](https://github.com/HanaCherry/aimusic-desktop/releases/tag/v0.4.0)
2. הפעילו את קובץ .exe ועקבו אחר ההתקנה.
3. פתחו את AI Music Desktop והתחברו לשירות לפי הצורך.

> המתקין אינו חתום; Windows עשוי להציג אזהרה.

## פרויקט עצמאי

אפליקציה לא רשמית שאינה קשורה ל-AI Music. נדרש אינטרנט. אפקטים וניתוח תלויים בגישה לזרם השמע; בדיקות סינתטיות אינן מבטיחות כל קטע מקוון.

ההצגה זמינה ב-32 שפות. הממשק המקומי כרגע בצרפתית; שפת השירות נבחרת בתפריט שלו.

→ [NOTICE.md](NOTICE.md) · [aimusic.so](https://aimusic.so/fr/app)

## פיתוח

Node.js 22.12+ · pnpm · Windows x64

```sh
git clone https://github.com/HanaCherry/aimusic-desktop.git
cd aimusic-desktop
pnpm install --frozen-lockfile
node node_modules/electron/install.js
pnpm start
```

```sh
pnpm test
pnpm exec electron . --smoke-test
pnpm exec electron . --preview
pnpm dist
```

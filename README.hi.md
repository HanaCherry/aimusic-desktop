## आपके अनुरूप स्टूडियो

- **एकीकृत प्लेयर** — स्थिर कवर, पारदर्शी बार, रंगीन प्रगति और नीचे एक साथ प्लेबैक नियंत्रण।

- **रंग और माहौल** — Galaxy, Music, Night, Light और Official थीम। एल्बम कवर के रंग सुनने के अनुभव में साथ रहते हैं।

- **इक्वलाइज़र और प्रभाव** — दस बैंड, प्रीऐम्प, प्रीसेट, A/B, स्टीरियो चौड़ाई, पैन, ऑटो-पैन, रीवर्ब, इको और स्पेक्ट्रम।

- **स्थानीय प्रोफ़ाइल** — फ़ोटो और उपनाम जोड़ें। सेटिंग और ऑडियो प्रीसेट आपके कंप्यूटर पर रहते हैं।

- **स्टार्टअप कैश** — डिस्क कैश उपलब्ध संसाधनों का पुनः उपयोग करता है। इसे साफ़ करने पर सत्र और सेटिंग बची रहती हैं।

- **क्रेडिट दिखाई दें** — AI Music का बैलेंस देखें और सेवा के वास्तविक रचना उपकरण इस्तेमाल करें।

## अपना स्टूडियो खोलने के लिए तैयार हैं?

1. रिलीज़ पेज से Windows इंस्टॉलर डाउनलोड करें। → [v0.4.0](https://github.com/HanaCherry/aimusic-desktop/releases/tag/v0.4.0)
2. .exe फ़ाइल चलाएँ और स्थापना के चरणों का पालन करें।
3. AI Music Desktop खोलें और आवश्यक होने पर सेवा में लॉगिन करें।

> इंस्टॉलर हस्ताक्षरित नहीं है; Windows चेतावनी दिखा सकता है।

## एक स्वतंत्र परियोजना

यह अनौपचारिक ऐप AI Music से संबद्ध नहीं है। इंटरनेट आवश्यक है। प्रभाव और विश्लेषण ऑडियो स्ट्रीम तक पहुँच पर निर्भर हैं; कृत्रिम परीक्षण हर ऑनलाइन ट्रैक की गारंटी नहीं देते।

यह प्रस्तुति 32 भाषाओं में उपलब्ध है। ऐप का स्थानीय इंटरफ़ेस अभी फ़्रेंच में है; सेवा की भाषा उसके मेनू में चुनें।

→ [NOTICE.md](NOTICE.md) · [aimusic.so](https://aimusic.so/fr/app)

## विकास

Node.js 22.12+ · pnpm · Windows x64

```sh
git clone https://github.com/HanaCherry/aimusic-desktop.git
cd aimusic-desktop
pnpm install --frozen-lockfile
node node_modules/electron/install.js
pnpm start
```

```sh
pnpm test
pnpm exec electron . --smoke-test
pnpm exec electron . --preview
pnpm dist
```
